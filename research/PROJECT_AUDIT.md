## Data findings

All manifest files exist and decode; there are no duplicate manifest paths, conflicting labels, cross-split paths, or byte-identical files. The split is nevertheless unsuitable as the final benchmark: `19. House` and `97. dry` have no test samples. Signer ID is unavailable, so signer-independent generalization cannot be claimed. The full analysis is in `dataset_analysis/final_dataset_audit.md`.

## Why the current result is 11.05%

This is an exploratory test result only, not a valid final result.

1. The model sees a median of roughly 13 training videos per class (range 7–19), far too little for reliable 50-way RGB fine-tuning.
2. `MobileNetV3Baseline` averages frame embeddings, discarding temporal order; the LSTM version had only its final state but still froze almost all visual layers.
3. The current 16-frame uniform sampler, letterbox resize, RGB conversion, `[0,1]` scaling, and ImageNet normalization are internally consistent for training/evaluation. Backend resizing/scaling also matches. Inference instead requires the caller to supply exactly 16 already-sampled frames, so capture-time sampling is not centrally guaranteed.
4. Training uses a fixed batch size of 2, no seed, no balanced sampler/class weighting, no label smoothing, no gradient clipping, no resume support, and selects checkpoints by validation loss only. Existing runs do use AdamW and a plateau scheduler.
5. The evaluation script requires scikit-learn, which is not installed in the recorded environment; existing result CSVs are preserved but should be independently reproduced once the environment is fixed.
6. The prior test set was evaluated repeatedly and excludes two labels. It must remain exploratory and must not guide further tuning.

## Architecture and checkpoint checks

- Both models use ImageNet-pretrained MobileNetV3-Small when training and correctly suppress a pretrained download at checkpoint load.
- `mobilenet_baseline_letterbox_best.pth` is epoch 10 with validation loss 2.3259; the saved existing exploratory test accuracy is 11.05% (macro F1 0.0876).
- The checkpoint label order is present and has 50 labels. Backend loading and top-5 response construction match that mapping.
- No final checkpoint, calibration, locked evaluation, or reproducible experiment registry exists yet.

## Decision

Do not train another RGB architecture yet. Keep the 50-label vocabulary and retain INCLUDE-50 as a local baseline, but first obtain data with documented signer metadata and confirm exact label overlap. The highest-value route is access to a large multi-signer isolated-ISL corpus for pose pretraining and then a locked, balanced 50-label evaluation protocol. See `dataset_analysis/alternative_datasets.md`.

## Safe next implementation

After dataset approval: add a deterministic manifest/split builder, centralize train/inference preprocessing, add a reproducible controlled baseline (seed, class balancing, resume, metrics), and run one validation-only experiment. No frontend changes are required.
