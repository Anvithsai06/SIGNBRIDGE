SIGNBRIDGE 🤟

Real-Time Indian Sign Language Recognition and Translation Using Deep Learning

Overview

SIGNBRIDGE is a research-oriented Deep Learning project that aims to recognise Indian Sign Language (ISL) through visual input and translate signing sequences into readable English text.

The system uses Computer Vision, Deep Learning and Natural Language Processing to develop an accessible communication interface.

Objectives

* Recognise Indian Sign Language gestures.
* Process dynamic signing sequences.
* Develop continuous sign recognition.
* Translate recognised signs into English text.
* Support optional text-to-speech conversion.
* Investigate signer-independent recognition.
* Compare multiple Deep Learning architectures.
